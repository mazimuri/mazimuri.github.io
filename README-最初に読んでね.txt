CAST / SIGNAL — GitHub Pages 公開用スターター

このフォルダは閲覧専用です。管理画面・ログイン・ブラウザ保存機能は含みません。

1. GitHub の mazimuri/mazimuri.github.io を開く
2. Code → Add file → Upload files
3. このフォルダの index.html, style.css, data.js, app.js, assets フォルダ内の画像3枚、および .nojekyll をリポジトリ直下にアップロード
4. Commit changes を押す
5. GitHub Pages の公開URLで表示を確認

重要：これは試作品に含まれていたサンプル3人のデータです。
V5.6の BACKUP JSON をここに勝手に上書きしても表示は変わりません。
