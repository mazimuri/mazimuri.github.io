## 目指すユーザー体験
`WORLD SELECT → WORLD DETAIL → STORY FILES（作品/zeta）`
または `WORLD DETAIL → CONNECTED CAST → PROFILE → 他作品・WORLD`。

- 03 WORLDSは **まず探す・見比べるページ**。現行3件をPCの初期画面内で見渡せる3列の一覧性を優先。
- WORLD DETAILは **世界の舞台・設定を理解するページ**。巨大なバナーは不要。タイトル・副題（代表作品）・概要を冒頭で読みやすく提示。
- STORY FILESは**作品への誘導の中核**。MAIN STORYは視覚的に強調し、SIDE STORYは補助的に並べる。各作品の登場キャラ顔と名前・既存URL・クリック遷移は維持。
- CONNECTED CASTからキャラ詳細へ進め、回遊性を高める。新たな架空リンクを作らない。
- グラフィックは「テンションはゼンゼロ、整理の上手さはエンドフィールド」。太いタイポ、厚みのあるゲームパネル、斜めカット、選択時だけ黄色。画像のアクセントカラーを競合させすぎない。
- フルHD（1920×911）と2K（2560×1271）の両方で、見た目の占有率・カード密度を確認。スマホは一列にする。

## WORLD名と作品タイトル
- 世界観/シリーズをまとめる論理単位として **WORLD名は存続**。
- ただし単発作品なら作品名をWORLD名にしてもよい。無理に架空の地名・世界名を創作する必要はない。
- 「副題・ストーリータイトル」は表示名と入力欄の意味が曖昧なため、後で「代表作品／キャッチコピー」への改善を検討。
- MAIN STORYの作品タイトルはSTORY FILESで独立して管理。リンク先やストーリー所属は変更しない。
- 後に、一覧の短いsummaryとは別に**任意入力の詳細世界観説明**を設けることを検討（今回の試作では既存データのみ使用）。
