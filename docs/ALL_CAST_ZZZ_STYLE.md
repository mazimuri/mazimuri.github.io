# CAST // SIGNAL — ALL CAST / ZZZ SELECT (2026-11-22)

## ユーザー採用デザイン（正式な設計判断）
- 方向性は「テンションはゼンゼロ、整理の上手さはエンドフィールド」。
- キャラ画像の彩度を主役にし、カードのフレームを黒・グレーで抑える。
- zeta（黄緑）とNEW（ピンク）は共通UIチップとして視認性を確保。
- 既存の小さなカードを多数見渡せる一覧密度、**6列**を重視。
- 黒いカートリッジ風カードをまとめた一体型のフレーム。
- 黄色い枠はホバー／キーボードフォーカス時のみ。選択状態の永続保持はしない。
- クリックは既存の `choose(id)` を維持（キャラクターのSELECTページへ）。
- キャラが増えればフレームが無制限に伸びるのではなく、内側のカード一覧だけスクロールする。
- キャラごとに保存済みのALL CAST画像クロップはそのまま使う。
- DETAILとスマホ（800px以下）の既存表示／動作は保持する。

## 実測基準
| Chrome内側の表示領域 | カード幅 | 列数 | フレーム幅の目安 |
| --- | ---: | ---: | ---: |
| Full HD 1920×911 | 151px | 6 | 約1026px |
| 2K 2560×1271 | 約201px | 6 | 約1345px |

- フルHDと2Kでカードの**画面占有率をほぼ一定**にする。
- CSSは `clamp(151px, 7.8646vw, 202px)` を起点にカード・写真高さ・字・バッジ・グリッド間隔も連動。
- PCの中間幅は4〜5列に落とし、狭すぎる表示を回避。
- 48枚のレイアウトテストは公開済みキャラの画像複製を用いる。個人の非公開キャラ情報はコミットしない。

## CSS / JS の所有範囲
- `cast-allcast-current.css` : ALL CASTのデスクトップ版GALLERYデザイン唯一の現行モジュール。
- `cast-side-rail.css` : SELECT・右レールと ALL CASTヘッダーの既存定義。Study12の旧ギャラリー上書きは削除済み。
- `style.css` : サイト全体のベースと、画像クロップ共通仕様。新モジュールは既存 `object-fit:cover` と `allCastCrop` を再利用。
- `app.js` : 既存 `renderDirectory` とクリック／SEARCH／FILTER／DETAILを維持しつつ、スクロール表示・進捗だけ追加。
- `index.html`／`admin.html` : どちらも同じ CSS とマークアップ。
