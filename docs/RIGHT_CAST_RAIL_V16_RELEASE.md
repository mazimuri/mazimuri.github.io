## 参照デザイン

ユーザーが最終確認した `CAST_SIGNAL_A_DARK_STATUS_CLEAN_FIXED.html` のA配置を基準にする。V16.6からインジケーターなし、V16.7 Aの配置、暗い統合ステータス窓、V16 DEPTH彩度、モジュール感を継承。

- 4枚を奥→手前に大きくしたパース配置。実データを使い4人以上にも対応。
- カードの暗い金属風ケース、写真ベイ、構造的な黒い名前パネル。
- ステータスは黒いパネル内の黄緑（zeta）・赤（NEW）の**小さな縦ライン**。色の付いたベタ塗りバッジは使わない。
- 最遠2枚のみZ/N、手前2枚はzeta/NEW。表示は実データ（`.zeta-badge`, `.cast-new`）から生成し、試作の仮データは使わない。
- ステータスはカード外枠内の名前窓左側、顔に被せない。
- インジケーターLEDは撤去（`::before`擬似要素を出さない）。右上のごく細いケース反射のみ。
- カードホバーでフレームが **-2px/-2px** 浮く。画像への新しいフィルターやフレーム全体の明度フィルターは掛けない。
- 奥モノクロ→中間→選択中カラー（DEPTH）。
- ALL CASTは選択カード左側の独立横向きボタン。カード下端に揃え、狭い画面はサイズを抑制。
- V15.4の上部パース矢印、キャラ選択、4人スキップ、ホイール、キーボード、画像編集値（crop-x, crop-y, crop-zoom）、DETAIL表示、モバイルは既存機能を保持する。
