# CAST // SIGNAL — ALL CAST / CHARACTER DECK V2

2026-11-22 / ユーザー採用：**PAPER（白いネームプレート）**

## ビジュアルデザイン
- WORLD SELECT V5 と WORLD DETAIL V4 に共通する黒・白・グレー＋蛍光イエローの工業的なゲームUI。
- 上部：赤い縦線、「02 / CHARACTER IDENTIFICATION SYSTEM」、大胆なALL CHARACTERS、明るい検索UI、フィルター／表示切り替え。
- 下部：暗い工業的なCHARACTER DECKの枠と管理番号02、6列のキャラクターアーカイブ、内部スクロールと進捗。
- **カード画像は従来と同じ縦横比・151px（FHD）～202px（2K）・6列**を維持。
- 画像直下にオフホワイトのネームプレート。名前は黒、職業等の短い補足はグレー。zeta/NEWは黒い下段に視認性高く固定色。
- 自分のキャラを探す際に現在位置の「SELECTED」マーカーを維持。黄色ホバー、画像個別クロップ、クリックでSELECTへ、DETAIL切替、検索フィルターは維持。
- スマホでは2列密度を保ち、明るいネームプレートを使うがデスクトップの大型装飾は出さない。
- 48件でリストが画面外に伸びず、内部スクロールすることを検証する。
