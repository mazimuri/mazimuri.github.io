# RIGHT CAST RAIL / WORLD RETURN / ALL CAST — V18 UX Design Review

2026-11-22。ユーザー確認用の検証ブランチ。**main/公開サイトにはまだ未適用**。

## 採用候補の操作ルール

| 操作 | 動作 |
| --- | --- |
| キーボード ↑ / ↓ | 前 / 次のキャラを1人ずつ切り替え |
| Shift + ↑ / ↓ | 4人ジャンプ（キャラが4人以下なら1人ずつ） |
| レール上の上 / 下矢印 | 1人ずつ切り替え、既存のレールモーションあり |
| Shift + レール上の上 / 下矢印 | 4人ジャンプ。中間のキャラを何度も選ばず1回のモーション |
| マウスホイール | 1人ずつ切り替え、従来の連続鑑賞モーション |
| 遠近レール内のカードクリック | 目的のキャラへ直接1回で切り替える。奥のカードの複数回中継をやめ、同一カードをFLIPで手前へ |
| ALL CASTボタンのホバー | 蛍光イエローのボタンを黒に反転し、黄色の文字・枠に変える |

※ キャラが4人の場合は4人ジャンプが同じキャラに戻ってしまうため、Shift操作も1人移動とする。

## ページ間回遊

- WORLD DETAILのCONNECTED CASTからPROFILEへ移動した際、上部に**「↶ ロジエ邸へ戻る」**のようなボタンを表示する。
- ボタンを押すとWORLD DETAILの**元のスクロール位置**へ戻る。
- SELECTやALL CASTから直接開いたPROFILEではこのボタンは出さない。
- WORLD名やキャラの所属は、現在公開されているデータのIDを利用する。新たなデータ構造を管理者に要求しない。

## ALL CAST内の現在位置

- 現在SELECTで選んでいるキャラは、ALL CASTで **◈ SELECTED** を表示。
- 一覧を開いたときそのカードが見えるように、一覧のスクロール位置を調整。
- 他のキャラをホバーすると黄色いホバー枠は従来どおり動く。SELECTEDバッジは本人だけ。
- GALLERYとDETAIL表示の両方で選択中を示す。

## 視覚設計

- 4枚のカードの遠近、比率、画像の保存済み切り抜きと位置、個別ACCENTは変更しない。
- 既存のホバー黄色とゼンゼロ風の操作感を維持し、追加ボタンでレールを窮屈にしない。
- 関連変更は現行JSと単一のナビゲーションCSS `cast-navigation-current.css` に集約。不要な過去バージョンのCSS上書きは増やさない。
- 本番適用前に1920×911、2560×1271、390×844で操作と画面遷移を確認。

## 検証上の注意

キャラ数が多いときの操作を確認するため、ブラウザ内だけで一時的に12件以上になるようダミーを追加するテストを用意。**GitHubの公開コンテンツやEDIT MODEの登録データにはダミーを追加しない**。

次の実装判断：素早いカードクリックを一回の移動にするか、従来の「段階的に見せる」演出を残すかを、プレビュー体験で比較して決める。
